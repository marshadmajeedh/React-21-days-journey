# React Learning Journey

A structured React learning project focused on becoming comfortable building React applications independently.

## Goal

Learn React fundamentals and gradually progress toward building production-style React applications without relying on step-by-step tutorials.

Target completion date: **October 20, 2026**

## Learning Plan

The project will gradually cover:

- React fundamentals
- JSX
- Components
- Props
- State with `useState`
- Events and forms
- `useEffect`
- Custom hooks
- React Router
- Context API
- React Hook Form
- Zod validation
- Axios
- TanStack Query
- API integration
- Feature-based architecture
- Protected routes
- Performance optimization
- Production practices

## Day 1 - React Fundamentals

### Topics Covered

- Created a React application using Vite
- Understood the basic React project structure
- Learned the role of `main.jsx` and `App.jsx`
- Learned JSX syntax
- Used JavaScript expressions inside JSX
- Created reusable React components
- Imported and exported components
- Built a basic component tree
